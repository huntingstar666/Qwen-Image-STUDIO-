# 前端改版开发方案（Apple 风格 · 作品画廊 · 素材仓库 · 图片精修）

> 状态：已确认并执行完毕（阶段 1-5）  
> 基线提交：`e5df3e0 chore: 初始化版本库（前端改版前基线）`  
> 维护方式：每完成一个阶段，更新本文档的「阶段进度」与「变更记录」，并单独提交一次 Git。

---

## 1. 目标与边界

### 1.1 目标

1. 按 Apple / macOS App 的审美重做前端外壳：简洁、克制、专业，减少视觉噪音，强化层级、留白与操作反馈。
2. 保留现有色卡（暖白 / 墨绿 / 暖赭），补齐**亮色 + 暗色**两套主题，支持跟随系统。
3. 新增三个模块：
   - **作品画廊**：分类卡片浏览精选作品、提示词、种子；一键把提示词发送到文生图工作台。
   - **素材仓库**：只收录用户主动收藏的满意作品与本地素材，区别于全量历史记录。
   - **图片精修**：PS 式工作台前端，支持基础图像编辑、蒙版绘制，并可将「底图 + 蒙版 + 提示词」送入图像编辑页。
4. 保持纯原生 ES module + 原生 CSS，零构建、零 npm、零框架。
5. 数据结构单一来源，收藏 / 上传 / 编辑均持久化，不在多处重复定义字段。

### 1.2 边界

- 本期不实现新的模型推理能力；图片精修的「AI 局部重绘」仅完成前端闭环与交接，实际出图沿用现有 `POST /api/edit`。
- 作品画廊本期使用**渐变占位封面**（用户已确认），不引入外部图片与版权风险；数据结构预留 `cover` 字段，后续可无缝替换为真实图片。
- 不重写文生图 / 图像编辑 / 图像处理的业务逻辑，只做视觉与布局适配；必要的交互增强（收藏、交接）以最小改动接入。

## 3. 视觉与交互规范

### 3.1 设计原则

- **内容优先**：弱化边框与装饰，靠留白、字号、明度区分层级。
- **一个主色**：墨绿只用于主操作、选中态与关键状态；暖赭只用于强调与品牌点缀。
- **克制的圆角与阴影**：面板 14–16px，控件 8–10px，阴影只用于浮层。
- **动效短而轻**：120–200ms，`cubic-bezier(0.22, 0.61, 0.36, 1)`，尊重 `prefers-reduced-motion`。
- **状态可感知**：悬停、按下、禁用、加载、空状态、错误六态齐全。

### 3.2 设计令牌（单一来源：`web/assets/css/theme.css`）

亮色沿用现有色值；暗色为同色相的低明度映射：

| 令牌 | 亮色 | 暗色（拟） |
| --- | --- | --- |
| `--bg` | `#faf8f4` | `#14161a` |
| `--bg-2` | `#f6f2eb` | `#191c21` |
| `--panel` | `#ffffff` | `#1e2227` |
| `--panel-2` | `#f6f2eb` | `#242930` |
| `--line` | `#e7e1d7` | `#2e343b` |
| `--text` | `#23262b` | `#ece9e4` |
| `--text-2` | `#5c6169` | `#b7b3ad` |
| `--muted` | `#8b9099` | `#8d949d` |
| `--accent` | `#2f6b62` | `#6fb3a8` |
| `--violet` | `#b87340` | `#d89765` |

- 通过 `html[data-theme="light|dark"]` 切换；默认 `system`，监听 `prefers-color-scheme`。
- 所有组件只使用令牌，不再出现硬编码 `#fff` / `rgba(...)` 颜色。
- 字体：系统栈优先（SF Pro / PingFang SC），品牌保留衬线字，正文与控件统一无衬线。

### 3.3 外壳

## 4. 模块设计

### 4.1 作品画廊（`#gallery`）

**定位**：灵感与复刻入口，不是用户资产。

- 顶部：标题、搜索框、分类 chips（全部 / 人像 / 风景 / 产品 / 建筑 / 插画 / 概念 / 字效）、收藏筛选。
- 卡片：4:5 渐变封面（分类专属渐变 + 噪点 + 大字编号）、标题、分类标签、提示词摘要、种子（无则显示「—」）。
- 悬停：轻抬升 + 显示「发送到文生图」「收藏」两个快捷操作。
- 详情弹窗：大封面、完整提示词、负向提示词、种子、比例、来源标注、操作：
  - **发送到文生图**：写入提示词、负向提示词、种子、宽高，跳转 `#t2i`。
  - **收藏到素材仓库**：写入仓库（无图片时使用同款渐变封面）。
  - 复制提示词。
- 数据：`web/src/data/gallery.js` 静态导出，24 条左右；字段见 §5.1。提示词参考公开的 Qwen-Image 案例，来源链接记录在 `source` 字段。
- 封面不依赖网络，渲染零成本。

### 4.2 素材仓库（`#materials`）

**定位**：用户主动收藏的「满意作品」与本地素材，和全量历史区分。

- 顶部：标题、搜索、类型筛选（全部 / 文生图 / 图生图 / 本地素材）、分类 chips、排序（最近 / 名称）。
- 卡片：封面（真实缩略图；无图时渐变）、标题、类型标签、分类、提示词摘要、种子。
- 详情弹窗：
  - 大图 / 渐变封面、提示词、负向提示词、种子、参考图（图生图）、参数摘要、备注。
  - 编辑标题 / 分类 / 备注。
  - 发送提示词到文生图；在图片精修中打开；下载；删除。
- 上传：拖拽 / 选择图片，支持批量；上传后进入「本地素材」，无提示词。
- 收藏入口：
  - 作品画廊卡片 / 详情；
  - 文生图与图像编辑的结果卡片；
  - 历史记录详情。
- 收藏时后端把结果图复制到 `storage/materials/`，避免历史清理后仓库图片失效。

### 4.3 图片精修（`#studio`）

**定位**：轻量 PS，聚焦「基础调整 + 蒙版 + AI 局部精修交接」。

布局：

```
┌────┬──────────────────────────────┬──────────────┐
│工具│        画布舞台               │ 右侧检查器    │
│栏  │  （缩放/平移/裁剪框/蒙版）     │ 调整 / 裁剪   │
│    │                              │ 蒙版 / AI 精修│
├────┴──────────────────────────────┴──────────────┤
│ 状态栏：尺寸 / 缩放 / 坐标 / 蒙版覆盖率            │
└──────────────────────────────────────────────────┘
```

功能清单（本期）：

- 打开：拖拽、点选、粘贴；素材仓库「在图片精修中打开」；支持 PNG / JPG / WebP。
- 视图：滚轮以光标为中心缩放、抓手 / 空格平移、适配窗口、100%、显示蒙版叠加。
- 工具：抓手、裁剪、蒙版画笔、橡皮、矩形、椭圆。
- 调整：曝光、亮度、对比度、饱和度、色温、色调，实时预览、一键重置。
- 变换：左 / 右旋转 90°、水平 / 垂直翻转、应用 / 清除裁剪、全部重置。
- 蒙版：画笔大小 / 硬度 / 不透明度、反相、清空、覆盖率实时显示；蒙版与画面同坐标系，裁剪后仍精准对齐。
- 历史：撤销 / 重做（最多 30 步），快捷键 `Ctrl+Z` / `Ctrl+Shift+Z`。
- 输出：导出 PNG / JPEG、复制到剪贴板、收藏到素材仓库、导出蒙版。
- AI 局部精修：提示词交给下游图像编辑页，**送入图像编辑** 烘焙当前图像 + 蒙版 → 跳转 `#edit`，自动带图并开启局部编辑；未绘制蒙版时给出中文提示。
- 快捷键：`V` 抓手、`C` 裁剪、`B` 画笔、`E` 橡皮、`R` 矩形、`O` 椭圆、`[` `]` 笔刷大小、`0` 适配、`1` 100%、`Esc` 取消。

架构（可维护、可扩展）：

- `studio.js`：页面骨架、工具绑定、检查器、快捷键、指针交互与画布合成展示。
- `studio/studioDoc.js`：非破坏式文档模型。保存原图 + 变换（旋转 / 翻转 / 裁剪）+ 调整参数 + 蒙版画布；`renderBase()` 负责合成，展示与导出共用同一管线。
- 历史快照保存变换、调整参数与蒙版画布副本，上限 30 步；撤销 / 重做同时恢复蒙版。
- 图层能力本期只保留「图像 + 蒙版」两层结构，为后续多图层预留文档模型，不提前实现。

## 6. 后端接口（新增）

新增 `server/materials.py`，索引文件 `storage/materials.json`，图片目录 `storage/materials/`，写入使用临时文件 + `os.replace` 原子落盘 + 线程锁。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/materials?kind=&category=&q=&limit=` | 列表，按收藏时间倒序 |
| POST | `/api/materials` | 新建收藏；可带 `image`（dataURL 或 `/files/...`），后端负责落盘 / 复制 |
| PATCH | `/api/materials/{id}` | 修改标题 / 分类 / 备注 / 标签 |
| DELETE | `/api/materials/{id}` | 删除记录与仓库自有图片 |
| POST | `/api/materials/upload` | 本地上传（multipart），直接生成 `kind=upload` 素材 |

- 图片字段统一返回 `/files/materials/...`，前端通过 `api.fileUrl` 兜底。
- 不修改现有 `/api/history` 与任务队列行为。

## 9. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 现有 `app.css` 大量硬编码颜色，暗色遗漏 | 阶段 1 先做令牌化扫描，阶段 5 逐页巡检；新增样式禁止硬编码颜色 |
| 侧边栏改动影响现有页面布局 | 保持 `.page` 容器与页面内部结构不变，仅调整外层；每阶段浏览器实机验收 |
| 素材图片重复占用空间 | 收藏历史图时复制而非引用；删除素材时只删除仓库自有文件 |
| 精修撤销占用内存 | 操作序列 + 蒙版压缩快照，限制 30 步 |
| 画廊渐变封面显得单薄 | 分类渐变 + 噪点纹理 + 大字号编号 + 标题排版，保证质感；预留真实封面字段 |
