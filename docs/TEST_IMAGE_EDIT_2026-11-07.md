# 图片编辑能力测试档案（2026-11-07）

> 范围：`/api/edit` 全链路（预设 / 参数 / 遮罩几何 / 合成 / 预处理 / LoRA / 质量报告）
> 目的：验证 12 类真实使用场景，每类 ≥3 轮，记录参数、耗时、像素指标与视觉结论；
> 失败必须归因到「LoRA 或设置没选对 / 内部代码逻辑 / 模型能力」三类之一，并修复可修复项。

## 1. 测试环境

| 项 | 值 |
| --- | --- |
| 后端 | `server.main:app` @ `http://127.0.0.1:8722` |
| 模型档 | Qwen-Image 2.1 Turbo（`qwen_image_2.1_turbo_int8_convrot`，9 步手写 sigma） |
| 采样 | euler / simple / cfg 1.0（Turbo 档）；显式覆盖用例单独标注 |
| 预设版本 | `PRESET_VERSION = 1`（`/api/meta.edit_presets` 唯一事实源） |
| LoRA | 一致性 `Qwen2.1 一致性无偏移_GH_V1.0` @0.48；移除 `Qwen2.1_万物移除Remove_GH` @1.0；扩图 `Qwen2.1_扩图_GH_3750` @0.7 |
| 硬件 | RTX 5090（测试时可用显存约 30 GB） |
| 素材 | 由 `/api/generate` 现场生成（seed 固定），水印 / 大图 / 红框由 PIL 合成，全部落 `.cache/test-runs/assets/` |
| 执行器 | `.cache/imgtest/run_tests.py`（12 类用例，结果 `.cache/test-runs/results.json`，图片 `.cache/test-runs/outputs/<case>/`） |

指标口径：

- `outside_max_abs`：遮罩外（含预设接缝带）允许的最大像素差；质量报告口径应是 0。
- `ΔE`：输出与输入（尺寸不同先 LANCZOS 缩回）的平均 Lab 色差。
- `changed_ratio`：像素差 >5 的占比。
- 视觉结论：人工查看每类首轮输出，记录「达成 / 部分达成 / 未达成」。

## 3. 发现的问题与处理

| 编号 | 现象 | 归因 | 处理 | 状态 |
| --- | --- | --- | --- | --- |
| P0-1 | `job.params.loras` 为空，预设/任务自动挂载的 LoRA 没有写回作业参数，历史回放与质量报告看不到实际挂载项 | 内部代码逻辑 | `pipeline.py` 在 `_build_loras` 后把真实 LoRA（文件名 + 权重）写回 `job.params["loras"]` | 已修复 |
| P0-2 | `preset=remove` + 显式 `task.mode=edit` 时，预设的 `local.hint=green_overlay` / `fills=true` 仍生效，模型参考图被画上绿块，普通编辑被「移除任务」的输入约定污染 | 内部代码逻辑（预设合并） | `presets.py` 合并后若显式任务与预设任务不一致，且用户没显式给 `hint`/`fills`，则任务专属键让位给新任务 | 已修复 |
| P0-3 | 显式 `steps=30/cfg=5` 与 Turbo 档同时存在时，实际按 9 步 / cfg 1.0 跑 | 设计如此（Turbo 档固定 sigma） | 不修；质量报告 `params.steps/cfg` 如实回显 9/1.0，文档明确「Turbo 优先」 | 记录 |
| P1-1 | 合照换人：遮罩最左侧男性 → 替换为红毛衣女性时，模型把新人物画到遮罩右边界，出现半身与硬接缝；同性别替换（男性→男性、女性→女性）正常 | 模型能力（跨性别/跨体型大幅替换） | 不违反几何契约（`outside_max_abs=0`）；用例改为「同性别替换」作为验收，跨性别失败留档 | 记录 |
| P1-2 | 手动统计的 `outside_max_abs` 大于 0（几十~两百），与质量报告的 0 不一致 | 统计口径：预设接缝带宽 4%/5%，接缝带属于允许变化区 | 不修；验收以质量报告 `quality.outside_max_abs` 为准，手工统计只作参考 | 记录 |
| P1-3 | 去水印用泛化指令（"移除画面中的水印"）时，斜向平铺文字被清掉，但左下 PIXSTOCK 徽章、右下 ID 编号保留；11a/11b/11c 均复现 | 提示词层面（模型对"水印"的默认理解偏文字） | 新增 11d：显式点名「斜向文字 / 徽章 / 编号」，3 轮全部清除；优化方案见 §6 O1 | 记录 |
| P1-4 | 连续 20 轮接力编辑：背景块平均差 1.50 → 26.03，ΔE 3.24 → 20.96，第 19 轮出现突变（背景块 13.96 → 31.59） | 累积误差 + 每轮全图重绘（无遮罩、无回归锚定） | 几何无偏移，属模型/流程层面的漂移；优化方案见 §6 O2 | 记录 |
| P1-5 | 0e 曾用「遮罩区绿通道增幅 <0.5」做泄漏断言，红→蓝替换本身就会抬高 G 通道（37~42），断言误报 | 统计口径错误（测试脚本，非产品代码） | 删除该断言，只用 `task_mode` / `hint_mode` 判定；绿通道差值留作参考 | 已修正 |

### 5.2 关键结论

1. **几何契约可靠**：所有有遮罩用例（0a、1c、4a-c、5d、6、9、10、11a/b/d）质量报告 `outside_max_abs=0`；扩图原图区平均差 <0.08；大图还原后尺寸与像素完全一致。零偏移链路（32 对齐 + latent==画布 + MaskCropV2 + CropRestore + 遮罩外合成）在 111 次真实请求中未出现一次破坏。
2. **预设系统按优先级工作**：显式 > preset > 后端默认；Turbo 是唯一"反向覆盖"显式参数的特例，且质量报告如实回显。修复 P0-2 后，跨预设任务不再污染输入。
3. **LoRA 自动挂载正确**：一致性 LoRA 在普通编辑默认 0.48；Remove 预设自动挂 `万物移除Remove_GH@1.0` 并开绿色提示；扩图挂 `扩图_GH_3750@0.7`；姿势用 `VNCCS_QI2_PoseStudioV1.1@0.85`。P0-1 修复后可审计。
4. **性能**：1024×768 局部编辑稳态 1.2~1.6s；新建编辑 2~6s；3000×5000 单轮 4~5s；首轮 40s 是模型加载。显存稳定 13283MB。
5. **能力边界**：跨性别/大幅体型换人（P1-1）、连续无遮罩多轮重绘（P1-4）、泛化去水印（P1-3）是当前模型/提示词层面的真实短板，不是几何或管线 bug。

### 5.3 遗留风险

- 长会话连续编辑若不做遮罩/回锚，色偏会累积，用户会感知"越改越不像原图"。
- 去水印类需求若用户只写"去水印"，会漏掉徽章/编号，需要产品侧兜底提示词。
- 手工统计口径（未排除接缝带）容易误判为"像素偏移"，后续报告统一以 `quality` 为准。
- 大图当前依赖 `max_side=2048`；若用户要求局部细节（如 5000px 上的小字），缩放会丢细节，需在 UI 提示"大图模式适合整体编辑"。

## 6. 优化方案

> 原则：先修代码确定性缺陷（已完成 P0-1/P0-2），再改提示词模板，最后才是模型侧能力；每条给出验收口径。

### 6.1 O1 去水印提示词模板（优先级 P0，提示词层）

- 现状：`preset=remove` / `native` 下，"移除水印"只清文字，漏徽章/编号（11a/b/c）。
- 方案：
  1. 前端"去水印"入口内置模板：`移除画面中的水印，包括斜向平铺文字、角标徽章/logo、编号/日期等所有叠加元素，保持底层画面不变`。
  2. 后端 `pipeline` 在 `task.mode=remove` 且提示词含"水印"时，若未提及"徽章/编号/logo"，自动追加上述限定语，并在 `quality.warnings` 里提示已补全。
  3. 保留"仅去文字"的高级开关，避免误删画面内真实文字（招牌/书名）。
- 验收：11d 提示词模板化后，用 11a/11b/11c 同款泛化输入，3 轮视觉检查徽章与编号均消失；`outside_max_abs=0`。

### 6.2 O2 连续编辑防漂移（优先级 P0，流程层）

- 现状：20 轮全图重绘，背景块差 1.50 → 26.03，r19 突变（P1-4）。
- 方案：
  1. 连续编辑默认携带"上一轮遮罩"：只重绘用户圈选区域，遮罩外走 byte-exact 合成（几何契约天然抗漂移）。
  2. 每 N 轮（建议 5）提供"回锚"选项：以原始图 + 当前遮罩做一次局部编辑，或把原图作为第二参考图（`images=[current, original]`）+ 一致性 LoRA。
  3. UI 展示累计漂移提示：当 `delta_e_vs_original > 10` 或背景块 mean > 8 时提示"建议回锚"。
  4. 连续编辑默认 `turbo=true`、`seed` 固定为会话 seed，减少随机抖动。
- 验收：同一 20 轮脚本改为"每轮带遮罩"后，背景块 mean 增长 ≤ 5，ΔE(原图) ≤ 8；GIF 肉眼无明显色温跳变。

### 6.3 O3 跨性别/大幅换人（优先级 P1，提示词 + 流程）

- 现状：同性别替换正常，男→红毛衣女性会画到遮罩右边界并出现硬接缝（P1-1）。
- 方案：
  1. 换人提示词强制包含"新人物完整位于遮罩范围内，身体宽度与遮罩宽度一致，不得越过选区边界"。
  2. 遮罩自动外扩到目标人物完整轮廓（复用 `subject_mask` 思路做"贴合人物"按钮），避免遮罩小于人物。
  3. 兜底：`task.mode=edit` + `preset=mask_edit` + 一致性 LoRA 0.6；若首轮失败，自动重试一次并增大 expand_pct。
- 验收：男→女跨性别用例 3 轮中至少 2 轮无越界、无明显接缝；`outside_max_abs=0`。

### 6.4 O4 参数优先级可见化（优先级 P2，UI）

- 现状：Turbo 覆盖显式 steps/cfg 只在质量报告里可见（P0-3）。
- 方案：编辑面板在 Turbo 开启时把 steps/cfg/sampler 置灰并显示"Turbo 固定 9 步 / cfg 1.0"；切换"自定义"才可编辑。参数冲突（如 remove 预设 + edit 任务）即时提示实际生效值。
- 验收：面板回显与 `job.params` 一致；`/api/meta` 无需新增字段。

### 6.5 O5 质量报告与测试口径（优先级 P2）

- `quality` 增补：`preprocess.applied/scale/work`、`pose_lora`、`params.loras`（P0-1 已完成落库）、`outpaint.left/top`（已有）。
- 测试脚本统一以 `quality.outside_max_abs` 为几何验收，手工统计只输出参考值并标注接缝带。
- 验收：任意用例可从单条 `results.json` 复现全部结论。

### 6.6 O6 大图与性能监控（优先级 P3）

- 维持 `preprocess.max_side=2048`；新增日志字段：`preprocess.work/canvas`、`vram_before/after`（已有）、单轮耗时。
- 在 UI 大图模式提示"整体编辑优先；细节文字建议先用局部遮罩"。
- 验收：3000×5000 连续 10 轮显存波动 <500MB、无超时。

### 6.7 落地顺序

1. O1（提示词模板）→ 2. O2（连续编辑遮罩化/回锚）→ 3. O3（换人提示与遮罩贴合）→ 4. O4/O5（UI 与报告）→ 5. O6（监控）。
