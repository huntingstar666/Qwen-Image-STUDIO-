## 读法

| 列 | 含义 |
| --- | --- |
| 裁块 | 方案 B 实际裁出的窗口（`宽×高@x,y`，负值表示越界、用边缘众数色补） |
| 全图改动 | 整张画布的改动像素占比，小目标会被面积稀释，只作参考 |
| 遮罩内改动 | 遮罩范围内被改动的像素占比，**局部编辑是否真的生效看这一项** |
| 遮罩外最大差异 | 应为 0；native 不承诺（整图重绘）所以显示 — |

本次记录的两个结论：① 四条路线 `遮罩外最大差异` 都是 0（零色差成立）；
② `mask_changed_ratio` 能区分“删对了”和“几乎没动”，全图指标（0.4%~1%）无法区分。
